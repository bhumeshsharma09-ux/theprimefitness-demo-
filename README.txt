PRIME FITNESS website - static site, no build step.

DEPLOY
- Netlify / Vercel / Cloudflare Pages: drag the "prime-fitness" folder (or this zip) in. Publish directory = this folder.
- Any web host: upload index.html and the media folder to the web root (public_html).

EDIT
- Open index.html in a text editor and search for "SITE SETTINGS" near the bottom (the CONFIG block).
  Change phone numbers, WhatsApp number, address, hours, Instagram/Facebook/YouTube handles, map link.
- Photos and videos live in the media folder. Keep the same file names when replacing them.

NOTES
- The live Google map is switched on in this version (CONFIG.mapEmbed).
- Fonts load from Google Fonts, so the site needs an internet connection to show Bebas Neue / Manrope.
